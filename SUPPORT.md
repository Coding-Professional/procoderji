# Support

Start with the [README](README.md), [development guide](docs/development.md) and
[backend setup](backend/README.md). Guest practice runs without production credentials or a
backend, so include whether a problem affects guest practice, local accounts or a deployed service.

| You need to... | Where to go |
| --- | --- |
| Ask a setup or usage question, or discuss an approach | [GitHub Discussions](https://github.com/procoderji-com/procoderji/discussions) |
| Report a reproducible bug | [Bug report](https://github.com/procoderji-com/procoderji/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/procoderji-com/procoderji/issues/new?template=feature_request.yml), after checking the [roadmap](https://github.com/procoderji-com/procoderji/issues/22) |
| Propose an original practice question | [Question proposal](https://github.com/procoderji-com/procoderji/issues/new?template=practice_question.yml) |
| Correct a question, explanation or published note | Open a bug report with the page/question ID, the correction and its reasoning, or submit a focused pull request |
| Report a vulnerability | Follow [SECURITY.md](SECURITY.md) privately |
| Report harassment or another conduct concern | Follow the private channel in the [Code of Conduct](CODE_OF_CONDUCT.md#report-a-concern) |

Search existing issues and discussions before opening another thread. Describe the page or
command, expected behavior, actual behavior, and relevant runtime/browser version. A small
reproduction is more useful than an entire project or a screenshot without context.

Remove passwords, tokens, connection strings and private student information from public logs,
screenshots and examples. Do not use a public issue for account-specific personal data.
For a private account or data concern, use the contact details in the
[privacy policy](https://procoderji.com/privacy).

Community help depends on maintainer and contributor availability.
