# seo/ - historical planning notes

These files were written for a different site (**RGPVNotes.in**) and are kept only as
background reading. They do **not** describe this project and nothing in the build uses them.

Do not copy domains, titles or outreach text from here. For ProCoderJii Notes:

- the canonical domain is `https://procoderji.com` (override with `NEXT_PUBLIC_SITE_URL`);
- `robots.txt` and `sitemap.xml` are generated by `src/app/robots.ts` and `src/app/sitemap.ts`;
- structured data comes from `src/lib/jsonld.ts`;
- per-page metadata comes from `src/lib/seo.ts`.

The old `robots.txt`, `sitemap-generator.ts`, schema templates and `redirects.csv` were removed
because they pointed at the wrong domain and routes that do not exist.
