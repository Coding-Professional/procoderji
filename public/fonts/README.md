# DM Sans

`dm-sans-variable.ttf` is the variable DM Sans font distributed by Google Fonts.
It is self-hosted with Next.js so reading the application does not request fonts
from a third-party server.

- Source: https://github.com/google/fonts/tree/main/ofl/dmsans
- License: [SIL Open Font License 1.1](OFL.txt)

Georgia, where used for editorial headings, is a system-font fallback.
